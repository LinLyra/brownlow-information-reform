# Data availability

No raw or player-level third-party data are redistributed in this repository while permissions remain unresolved.

To reproduce the analysis, an authorised researcher must obtain the source dataset independently, verify the hashes documented in `DATA_SOURCES.md`, and place files in a local non-versioned data directory. Do not commit those files.

Expected authorised filenames under `data/private/`:

- `brownlow_datathon_dataset.csv`
- `v2_1_coach_oof_predictions.csv`
- `2026_player_match_predictions.csv`
- `brownlow_2026_actual_votes.csv`

The repository currently provides protocols, analysis source, schemas, aggregate result tables, figures and immutable source hashes. This package must not be described as fully compliant with SSAC's open-data requirement until the conference or data owners approve the proposed access route.
